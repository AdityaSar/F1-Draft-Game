# F1 Draft - Spin. Bid. Race. 🏎️💨

An interactive Formula 1 fantasy draft and live broadcast simulation game ready for direct deployment via GitHub Pages without any frameworks or build steps.

## Features
- **Screen 0: Landing Page** - F1 dark mode aesthetics with chassis textures and glowing neon accents.
- **Screen 1: Setup & Customization** - Dynamic player counts, budget configurations, driver roster input with skill ratings (`Driver Name - Skill`).
- **Screen 2: Split-Screen Auction Room** - Canvas spinning wheel with smooth physics, idle drift, bidding modal ($0 min bid, PASS option), live table, graphical slot bars, and undo.
- **Screen 3: Live Track Simulator & Broadcast** - Real circuit vector outlines, realistic car physics, tyre compounds (Soft, Medium, Hard, Wet), fuel burn effect, overtaking logic with per-track difficulty, ~20s pit stops, Safety Cars, fastest lap tracking, and live telemetry feed.
- **Championship Ceremony Podium** - Kahoot-style sequential podium reveal (P3 ➔ P2 ➔ P1 champion), physical 3-step podium, floating gold trophy, confetti bursts, and FIA championship standings.
